# Project Summary

## Objective
Implement an MLflow-based Champion-Challenger
framework to evaluate and compare two candidate models.

## Implementation
- Logged model experiments using MLflow.
- Evaluated both candidate models.
- Compared model performance using evaluation metrics.
- Generated confusion matrices and prediction outputs.
- Identified the champion model.
- Registered the selected model in MLflow Model Registry.
- Generated predictions using the registered model.

## Deliverables
- Model evaluation metrics
- Model comparison results
- Prediction CSV files
- Confusion matrices
- MLflow experiment screenshots
- Model registry screenshots

## Status
Project implementation and GitHub upload completed.
